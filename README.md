## 03 / 做事的方式

**先解决问题，再打磨体验。** 从一个具体需求出发，让功能、界面和文档一起完善。

**把过程留下，把成果分享。** 用源码和开发记录说明工具怎么工作，也欢迎通过项目 Issue 交流反馈。
